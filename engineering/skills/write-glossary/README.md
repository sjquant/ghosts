# Write Glossary

Create or update a project's vocabulary with short definitions, canonical
terms, and names to avoid. Respects existing document formats.

New glossaries default to `/tmp/write-glossary-<safe-project-slug>.md`. A
supplied destination takes precedence, and requests to revise a specific
glossary edit that file.
