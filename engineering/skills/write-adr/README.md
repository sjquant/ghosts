# Write ADR

Write a compact decision record about architecture, technology, infrastructure,
security, engineering practices, or domain design. Starts with a title and a
short paragraph; adds status, alternatives, or consequences when useful.
Works independently of a glossary.

New records default to `/tmp/write-adr-<safe-decision-slug>.md`. A supplied
destination takes precedence, and requests to revise a specific record edit
that file.
