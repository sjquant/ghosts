# Quick Rules

한 번의 응답 안에서 탐지, 윤문, 자체검증을 끝내기 위한 핵심 규칙이다.

## 보존 대상

다음 구간은 탐지하거나 수정하지 않는다.

- 고유명사, 제품명, 모델명, 기관명.
- 수치, 날짜, 단위, 법률 조항, 수학·화학·통계 표기.
- 따옴표로 묶인 인용문은 발화자 표지가 없어도 기본 보호한다. 필자의 자문·강조임이 문맥상 명확한 수사 장치만 예외적으로 다룬다.
- LLM, GPU, API, MCP 같은 표준 기술 약어.

서법 보존: 당위·요구("~해야 한다")와 추측·유보("~일 수 있다", "~로 보인다")를 사실 단정으로 바꾸지 않는다. 반복을 줄일 때도 서법 표지는 유지하고 문장 배치나 형태만 바꾼다.

내용 앵커: 문장별 주어·목적어·보어의 핵심 명사·개념어를 먼저 표시한다. 조사·어미는 바꿀 수 있지만 앵커의 원형을 삭제하거나 동의어로 치환하지 않는다.

## 수정 순서

1. D 관용구
2. A 번역투
3. I 형식명사
4. G 완곡 표현
5. H 접속사
6. F 수식·명사화
7. B 영어 과다
8. C/J 구조·장식
9. E 리듬

## 핵심 패턴

| ID | 심각도 | 패턴 | 처방 |
|---|---|---|---|
| A-1 | S1 | `~에 대해(서)`가 한 문단에 3회 이상 밀집 | 일부만 목적격 조사로 직결한다. 단발 사용은 보존한다. |
| A-2 | S2 | `~를 통해/통하여`가 한 문단에 3회 이상 반복 | 일부만 `~로`, `~해서`, `~함으로써`로 분산한다. |
| A-3 | S1 | `~에 있어(서)` | `~에서`, `~을 볼 때`로 바꾼다. |
| A-4 | S2 | `~라는 점에서` 3회 이상 | `~서`, `~라는 이유로`로 줄인다. |
| A-5 | S2 | `~와 관련하여/관련된` | `~에`, `~의`, 목적격 조사로 줄인다. |
| A-6 | S2 | `~에 기반하여/바탕으로` 남발 | `~로`, `~을 보고`, `~를 근거로`로 바꾼다. |
| A-7 | S1 | `가지고 있다`, `회의를 가지다` | 동사·형용사로 환원한다. |
| A-8 | S1 | 이중 피동 `~되어진다` | 능동 또는 단일 피동으로 바꾼다. |
| A-9 | S2 | `~에 의해` 피동 | 행위자를 주어로 올린다. |
| A-10 | S2 | 같은 `~할 수 있다`가 4회 이상 반복 | 능력·허용이면 보존하고, 가능성·전망 문맥에서만 같은 서법의 `~할 수도 있다`·`~할 가능성이 있다`로 일부 분산한다. `~할 여지가 있다`는 가능성 의미가 확인될 때만 쓴다. |
| A-11 | S2 | `~을 위해`가 한 문단에 밀집 | `~려고`, `~도록`, `~위한`으로 일부만 바꾼다. 단발 사용은 보존한다. |
| A-15 | S2 | 추상 주어 + 만능 동사 | 구체 주어 또는 원인·근거 절로 바꾼다. |
| A-16 | S1 | 대명사 출현마다 직전 2문장의 선행 명사구 후보를 확인 | 후보 0개면 명사구 복원(확정 불가면 유지), 1개면 생략, 2개 이상이면 명사구로 되짚는다. 삭제 비율 목표는 두지 않는다. |
| A-18 | S2 | 명사 앞 긴 좌향 수식 | 문장을 나누거나 후치 동격절로 푼다. |
| A-19 | S2 | `~에서의/~에로의/~으로의/~에의/~으로부터의` | 절로 풀어 쓴다. 단순 `~의`는 제외한다. |
| A-20 | S2 | `~되고 있다/~지고 있다`가 한 문단에 3회 이상 | 의미가 유지될 때 일부만 단순 시제로 환원한다. |
| A-21 | S2 | `단순한 X를 넘어 Y` | `X만이 아니라 Y`로 풀되, 새 내용을 보태지 않는다. |
| A-22 | S2 | `~은/는 명확하다·분명하다` | 평가 술어를 걷고 명제를 직접 쓴다. 이미 논증한 결론이면 보존한다. |
| A-23 | S2 | `발판·토대·초석을 마련하다`, `지평을 열다` 전망형 | 은유를 원문에 있는 실제 결과로 풀되, 결과가 불명확하면 보존한다. 과거 사실·인용·실물 기반은 보존한다. |
| A-24 | S2 | `더 이상 ~ 않다/아니다`가 2회 이상 또는 결말부 재정의에 등장 | `이제`로 바꾸거나 변화 동사로 편다. 부정 명제를 긍정으로 바꾸지 않으며 해당 골격을 새로 만들지 않는다. |
| B-1 | S2 | 한글 용어 뒤 영어 괄호 반복 | 첫 등장만 병기한다. |
| B-2 | S2 | 번역 가능한 영어를 그대로 둠 | 의미를 해치지 않을 때 한국어로 옮긴다. |
| C-5 | S1 | 이모지 남발 | 칼럼, 리포트, 공적 문서에서는 삭제한다. |
| C-7 | S2 | `먼저/반면/결국` 3단 공식 | 접속사를 줄이거나 산문에 녹인다. |
| C-8 | S2 | `A인가, B인가`·`A가 아니라 B`·`~것이 아니라`·`~것은 아니다` 대구가 2회 이상 반복 | 하나만 남기고 나머지는 비대칭 평서문으로 푼다. 사람의 수사일 수 있으므로 연쇄가 아니면 보존하고, 전부 없애지 않는다. |
| C-9 | S2 | `(1)`, `(2)`, `(3)` 인덱싱 | 산문이나 단순 줄바꿈으로 바꾼다. |
| C-10 | S1 | 콜론 부제 `X: Y` 반복 | 헤딩을 짧게 하거나 평서형으로 바꾼다. |
| C-11 | S1 | 연결어미 바로 뒤 쉼표 | 문법상 필요 없으면 제거한다. 윤문 후 개수가 원문보다 늘면 실패다. |
| D-1 | S1 | `결론적으로`, `따라서`, `이를 통해`, `그러므로`, `요약하면`, `정리하면`, `정리하자면` 3회 이상 | 대부분 삭제하고 필요한 1-2개만 남긴다. |
| D-2 | S1 | `시사하는 바가 크다`, `주목할 만하다`, `간과할 수 없다` | 삭제하거나 구체 결론으로 바꾼다. |
| D-3 | S1 | `본질적으로`, `핵심적으로` | 대비에 필요하지 않으면 삭제한다. |
| D-4 | S1 | hype 어휘 반복 | 삭제하거나 원문 사실로 대체한다. |
| D-5 | S1 | 의인화된 추상 주어 | 사람, 기관, 평범한 주어로 되돌린다. |
| D-6 | S1 | `~할 때다`, `~시점이다`, `지금이야말로` 공식 결말 | 구체 서술로 낮추되, `~해야 한다` 같은 당위 표지는 다른 서법으로 바꾸지 않는다. |
| D-7 | S2 | `X에서 Y로` 반복 | 하나만 남기고 일반 서술로 바꾼다. |
| D-8 | S2 | `필요한/중요한 것은 X이다`, `문제는/핵심은 X다` 분열문 | 주어와 서술을 직결한다. |
| D-9 | S2 | `결국 ~로 이어진다`, `~에 직결된다` 결산 반복 | 인과 경로를 구체화하거나 단문으로 나눈다. `결국`·`이유다`를 새로 주입하지 않는다. |
| D-10 | S2 | 문장 말미 `~하는 이유다` 도치 결산 | `그래서 ~다`처럼 순방향으로 풀되 새 결산 공식을 만들지 않는다. |
| D-11 | S2 | 결말부의 `향후/앞으로/중장기적으로` | 실제 시점·조건이 원문에 있을 때만 살리고, 없으면 시간어를 줄인다. |
| D-12 | S2 | 독립 문장 `과제도 남아 있다/한계도 분명하다` | 문패를 덜고 원문에 있는 실제 과제·한계를 직접 쓴다. |
| D-13 | S2 | 에세이 결말의 `어쩌면/비로소/천천히` 공식 | 에세이 장르에서만 성찰 부사를 줄인다. |
| D-14 | S2 | `진단은 서늘하다/경고는 아프다` 같은 감각 술어 1회 이상, 사람 글에서 드문 개념 은유 1회 이상, 그 밖의 개념 은유 3회 이상, 또는 같은 은유 어근 3회 이상 반복 | 감각 술어는 구체 서술로, 반복 은유는 명제를 보존한 평서로 직역화한다. 중심 은유·명제 불명·새 은유 주입은 보존한다. 관통 은유도 가장 효과적인 1회만 남긴다. |
| E-1 | S2 | 문장 길이 균일 | 짧은 문장 또는 긴 문장으로 리듬을 섞는다. |
| E-2 | S2 | `~다` 종결 4회 이상, `~고 있다` 남발 | 종결과 시제를 섞고 단순 시제로 환원한다. |
| E-7 | S2 | 대화·구어의 말높임 불일치 | 한 화자·문단 안 말높임을 일관시킨다. |
| F-4 | S2 | `-성/-적/-화`, `-tion/-ment/-ness/-ity` 명사화 누적 | 동사·형용사로 환원한다. |
| F-5 | S2 | 추상 `~적 N` 체인 | 명사+명사 또는 구체 절로 바꾼다. |
| F-7 | S2 | `확대·강화·개선·확보·마련·구축` 같은 정책 동사가 추상 목적어와 함께 한 문단에 누적 | 실제 행위와 대상을 풀어 쓴다. 당위나 확신을 더하지 않는다. |
| G-1 | S2 | 같은 `~로 보인다/~로 판단된다/~라고 여겨진다` 반복 | 단정으로 바꾸지 말고 유보 강도를 유지한 채 형태만 바꾼다. |
| G-2 | S2 | 이중·삼중 완곡 `~할 가능성이 있을 수 있다` | 완곡 하나만 남기되 극성·확신도는 보존한다. |
| G-3 | S2 | `양쪽 모두`, `신중하게`, `균형` 4회 이상 | 근거가 충분할 때만 구체 비교나 조건으로 바꾼다. 근거가 약한 신호이므로 단독 판정하지 않는다. |
| H-1 | S2 | 문두 접속사가 한 문단에 3회 이상 반복 | 그 문단에서 일부만 덜어낸다. 문서 전체를 일괄 삭제하지 않는다. |
| H-3 | S2 | `이는`, `이 점에서`, `이 관점에서`, `이 말은`이 한 문단에 3회 이상 반복 | 일부만 본 서술로 직진한다. 단발 사용은 보존한다. |
| H-4 | S2 | `즉` 남발 | 기술 설명문이 아니면 1회 이하로 줄인다. |
| I-1 | S1 | `~인 것이다/~한 것이다`가 연속 3회 이상 반복 | 일부만 평서형으로 바꾸며, 단발 사용은 보존한다. |
| I-2 | S2 | `X은 ~라는 점에 있다` | `X는 ~다`로 쓴다. |
| I-3 | S2 | `~다는 뜻이다/~다는 의미다` | 의미를 문장 안에 녹인다. |
| I-4 | S2 | `~해야 한다/~할 필요가 있다/요구된다`로 끝나는 문단이 2개 이상 | 첫 문단을 제외하고 당위 문장을 앞·중간으로 이동한다. 삭제·병합·서법 치환은 금지한다. |
| I-5 | S2 | `~이/가 필요하다`를 일괄적으로 구체화 | 주체를 보완할 수 있을 때만 구체화하고, `~해야 한다`를 새로 늘리지 않는다. |
| I-7 | S2 | 출처 없는 `~다는 분석이다/평가다` 종결 | 출처가 있으면 보존하고, 없으면 직접 서술로 바꾼다. 출처를 만들지 않는다. |
| J-1 | S2 | 마크다운 볼드 남발 | 본문에서는 제거한다. |
| J-2 | 강조 따옴표 5회 이상 | 실제 인용이나 핵심 용례만 남긴다. |
| J-3 | 칼럼·리포트의 불릿 리스트 | 목록 구조가 필요 없으면 산문으로 통합한다. |

## 자체검증

1. 고유명사, 수치, 날짜, 따옴표로 묶인 인용문, 기술 약어와 문장별 핵심 내용 앵커가 보존됐다.
2. 변경률이 30% 이하이면 통과한다. 30% 초과 50% 미만이면 재검토 후 경고를 붙이고, 50% 이상이면 원문을 복원한다.
3. 장르가 이탈하지 않았다.
4. 문체 격식과 서법(당위·추측·유보)이 이탈하지 않았다.
5. 조건이 충족된 핵심 S1(`D-1~D-3`, `A-3`, `A-7~A-8`, `C-5`, `C-10~C-11`, `D-6`, `I-1`, `J-2`) 잔존이 0건이다. 반복·문맥 조건이 붙은 규칙은 해당 조건이 충족된 구간만 점검한다.
6. 새 비유, 수사, 주장, 인용, 예시를 추가하지 않았다.

실패한 항목이 있으면 해당 수정만 롤백하고 한 번 다시 시도한다. 그래도 실패하면 원문을 둔다.
