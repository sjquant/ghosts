한국어 텍스트의 문체, 리듬, 표현만 국소적으로 다듬는다. 번역, 요약,
맞춤법 교정, 사실 보강, 새 글 작성으로 확장하지 않는다.

## 적용과 경계

- 입력은 붙여넣은 텍스트 또는 `.txt`·`.md` 경로다. 경로는 읽기만 하며
  원본을 덮어쓰지 않는다. 다른 확장자 경로는 읽지 않고 지원 형식을 안내한다.
  파일을 읽지 못하면 이유를 알리고 중단한다.
- 한글 문장이 전혀 없으면 한국어 텍스트만 처리한다고 안내하고 종료한다.
  한국어와 다른 언어가 섞였으면 한국어 산문만 다듬고 다른 언어 구간은 보존한다.
- 사실, 주장, 수치, 날짜, 고유명사, 직접 인용, 법률 조항, 공식, 표준 기술
  약어와 원문의 인과·조건·불확실성은 바꾸지 않는다.
- 원문에 없는 비유, 예시, 주장, 인용, 전환, 강조를 추가하지 않는다. 장르와
  문체 격식을 유지하고, [references/quick-rules.md](references/quick-rules.md)에
  매핑되는 구간만 수정한다.
- 변경률이 30%를 넘으면 경고하고, 50%를 넘으면 전체 수정본을 버리고 원문을
  유지한 채 중단한다.

## 절차

1. [references/quick-rules.md](references/quick-rules.md)를 먼저 읽는다. 더
   정밀한 분류나 처방이 필요할 때만 [ai-tell-taxonomy.md](references/ai-tell-taxonomy.md)와
   [rewriting-playbook.md](references/rewriting-playbook.md)를 참고하며, 두 문서는
   quick-rules의 범위를 넓히지 않는다.
2. 입력이 파일 경로면 내용을 원문으로 삼고, 보호 대상과 quick-rules에 맞는
   후보 구간을 표시한다. 장르가 없으면 첫 300자로 `칼럼·에세이`, `리포트`,
   `블로그`, `공식 문서` 중 추정한다. 판단이 불명확하면 원문의 장르·격식을
   유지하고 새 장르를 만들지 않는다.
3. `D -> A -> I -> G -> H -> F -> B -> C/J -> E` 순서로 후보 구간만 수정한다.
   사용자가 문단·범주·강도를 지정하면 그 범위로 더 좁힌다.
4. quick-rules의 `## 자체검증` 1-6을 수행한다. 실패한 수정은 해당 구간만
   되돌려 최대 한 번 다시 시도하고, 재실패하면 원문을 둔다.
5. 긴 글이거나 판단이 애매할 때만 [references/metrics.py](references/metrics.py)를
   보조 지표로 사용한다. 지표는 판정이 아니다.
6. 원문 대비 바뀐 공백 단위 어절 비율(서식만 바뀐 부분은 제외)을 대략 계산해
   결과와 함께 보고한다.

## 출력

```markdown
완료. 변경률 약 X% / 등급 Y / 자체검증 N/6 통과

<윤문본>

핵심 탐지:
- A-2: N -> M
- D-1: N -> M

주요 변경:
- before -> after
```

수정할 구간이 없으면 `변경 없음`으로 표시하고 원문을 그대로 출력한다. 50%
초과로 중단하면 `중단. 원문 유지`를 명시한다. 탐지·변경 항목이 없으면 각각
`없음`으로 쓴다.

## 부분 윤문 지시

- "이 문단만": 요청한 문단만 수정한다.
- "번역투만", "관용구만", "이모지만": 해당 카테고리만 적용한다.
- "강도 낮춰": S1 수정만 적용한다.
- "강도 높여": S1·S2와 quick-rules에 매핑된 리듬 조정(E)만 신중하게 적용한다.
- "2차 윤문": 직전 결과를 입력으로 삼고 1차보다 좁게 수정한다. 범위를 다시 넓히지 않는다.

## 등급

- `A`: S1 잔존 0, S2 잔존 2 이하, 변경률 25% 이하(변경 없음 포함), 자체검증 6/6.
- `B`: S1 잔존 0, S2 잔존 4 이하, 자체검증 5/6 이상, 변경률 30% 이하.
- `C`: S1 잔존 1-2, 자체검증 4/6 이하, 저윤문 또는 과윤문 위험.
- `D`: S1 잔존 3 이상 또는 변경률 50% 초과. 중단하고 보고한다.
