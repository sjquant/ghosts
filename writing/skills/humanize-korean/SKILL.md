$ARGUMENTS

한국어 원문을 진단하고, 탐지된 AI 티가 있는 구간만 자연스럽게 윤문한다. 번역, 요약, 사실 검증, 전면 맞춤법 교정, 새 글 작성으로 작업을 넓히지 않는다.

## 입력 및 제한 사항

- 인자가 `.txt` 또는 `.md` 경로면 파일을 읽고, 읽지 못하면 오류를 보고한 뒤 추측으로 대체하지 않는다. 그 밖에는 붙여넣은 텍스트를 원문으로 사용한다.
- 한국어 구간이 없으면 이 스킬은 한국어만 처리한다고 알리고 종료한다.
- 장르가 지정되지 않으면 첫 300자로 `칼럼`, `리포트`, `블로그`, `공적 문서` 중 하나를 추정한다.
- [references/quick-rules.md](references/quick-rules.md)를 먼저 읽는다. 세밀한 분류나 처방이 필요할 때만 [references/ai-tell-taxonomy.md](references/ai-tell-taxonomy.md)와 [references/rewriting-playbook.md](references/rewriting-playbook.md)를 추가로 읽는다.
- 고유명사·제품명·기관명, 수치·날짜·단위, 법률 조항·공식·표준 기술 약어, 직접 인용은 탐지하거나 바꾸지 않는다.
- 코드 블록, URL, 링크 목적지, 태그, 템플릿 변수도 보존한다.
- 원문에 없는 사실, 주장, 인과관계, 비유, 예시, 인용, 전환, 강조를 추가하지 않는다. 장르와 문체 격식도 유지한다.
- 탐지된 패턴이 없으면 원문을 그대로 두고 변경 없음으로 보고한다.

## 실행 전 체크리스트

```text
- [ ] 입력·장르 확인
- [ ] 보존 구간 표시·AI 티 탐지
- [ ] 해당 구간만 윤문
- [ ] Any 검증 실패 또는 변경률 30% 초과?
- [ ] 재윤문·롤백 또는 결과 보고
- [ ] 최종 검증·출력
```

## 실행 루프

```text
[Start: 입력·장르 확인] → [규칙 읽기·탐지] → [해당 구간만 윤문]
                                      ↓
                    [Any validation failure or >30% changed?]
                         ├─ 아니오 → [결과·검증 요약 보고] → [Done]
                         └─ 예 → [실패 구간 롤백·범위 축소]
                                      ↓
                         [해당 구간만 한 번 재윤문·재검증]
                                      ↓
                    [Any validation still fails, >50% changed, or meaning lost?]
                         ├─ 아니오 → [결과·검증 요약 보고] → [Done]
                         └─ 예 → [전체 원문 복원·중단 보고] → [Done]
```

1. 보존 구간을 표시하고 AI 티를 탐지한다.
2. [references/quick-rules.md](references/quick-rules.md)의 수정 순서인 `D → A → I → G → H → F → B → C/J → E`를 따른다. 탐지되지 않은 구간은 건드리지 않는다.
3. quick-rules의 `자체검증` 1–6을 모두 수행한다. 실패한 수정만 롤백하고 같은 구간을 한 번만 다시 시도한다. 다시 실패하면 원문을 유지한다.
4. 원문 대비 변경 어절 비율을 대략 계산한다. 30%를 넘으면 범위를 다시 줄이고, 50%를 넘거나 의미 보존에 실패하면 전체 원문을 복원한다.

## 요청 범위와 강도

- `이 문단만`: 지정한 문단만 수정한다.
- `번역투만`, `관용구만`, `이모지만`: 해당 분류만 적용한다.
- `강도 낮춰`: S1 패턴만 수정한다.
- `강도 높여`: S1·S2와 신중한 S3 리듬 수정까지 적용한다.
- `2차 윤문`: 직전 결과를 입력으로 삼고 1차보다 좁게 수정한다.

## 보조 도구

긴 글이거나 판단이 애매할 때만 [references/metrics.py](references/metrics.py)를 사용한다. 사용법은 다음처럼 `--help`로 확인한다. 장르 인자는 `칼럼/에세이→essay`, `리포트→report`, `블로그→blog`, `공적 문서→formal`로 맞춘다.

```bash
python3 references/metrics.py --help
python3 references/metrics.py --input input.txt --genre essay
python3 references/metrics.py --text $'첫 문장입니다.\n둘째 문장입니다.' --genre essay
```

## 출력

다음 순서로 응답한다.

```markdown
완료. 변경률 약 X% / 자체검증 N/6 통과

<윤문본>

핵심 탐지:
- A-2: 원문 구간 → 윤문 구간

주요 변경:
- 무엇을 줄였는지 한 줄로 설명
```

재윤문 후에도 변경률이 30%를 넘으면 경고를 붙인다. 검증에 실패해 복원하거나 작업을 중단하면 `완료` 대신 그 사유와 원문 유지 여부를 보고한다.
